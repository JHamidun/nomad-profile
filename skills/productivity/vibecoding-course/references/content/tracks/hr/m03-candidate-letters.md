# Миссия 3 — Письма кандидатам без копипасты

ROLE: hr
GOAL: Ученик умеет из шаблона и таблицы скрининга генерировать персональные письма каждому кандидату — и проверять факты в письмах против резюме, а не верить агенту на слово.
WHY: После шортлиста наступает самая прокрастинируемая часть подбора: троим написать приглашение, остальным — отказ. В итоге отказы не уходят неделями, кандидаты пишут злые отзывы о компании, а «Уважаемый кандидат!» из копипасты добивает бренд работодателя. Шаблон + данные скрининга = каждому личное письмо за минуты. Но у генерации есть цена: агент может приукрасить факты — и рекрутер обязан уметь это ловить.

## Наставнику (как вести — читает Claude Code)

- НЕ лекция. Сначала спроси: как сейчас у него уходят отказы кандидатам — и уходят ли вообще. Пусть честно скажет. Если «висят неделями» — это и есть боль миссии.
- Скажи оценку времени: 30–45 минут.
- Дай сделать РУКАМИ, по одному микро-шагу:
  1. Шаблоны. Пусть попросит агента создать заготовки `sandbox/hr/letters/templates/invite.md` (приглашение на интервью) и `decline.md` (отказ) с плейсхолдерами вида {имя}, {позиция}, {конкретика из резюме}, {слоты времени}. И пусть перепишет обе заготовки СВОИМ тоном: если есть письмо, которое он реально отправлял и которым доволен, — пусть даст его агенту как образец тона. Шаблон — его голос, не голос агента.
  2. Генерация. Пусть попросит: «по report.md сгенерируй письмо каждому кандидату в sandbox/hr/letters/out/, по файлу на кандидата: кому вердикт "шортлист" — по шаблону invite, остальным — по decline; в каждом письме — минимум одна конкретика из резюме ЭТОГО кандидата; ничего не выдумывай, каждый факт должен быть в его резюме».
  3. Фактчек. Пусть возьмёт два письма и сверит с резюме: каждая конкретика («ваш опыт запуска продаж с нуля») действительно там есть? Нашёл выдумку — не правит письмо руками, а говорит агенту: «в письме N факт X — его нет в резюме, перегенерируй строго по резюме». Это ключевой навык всей миссии.
  4. Тон отказов. Пусть прочитает один отказ вслух (буквально). Звучит канцеляритом или обидно — правка конкретно: «убери "к сожалению, вынуждены", добавь, что сохраним контакт для похожих ролей».
- Точки помощи: письма звучат роботом → дай агенту образец реального письма ученика и попроси «перепиши в этом тоне»; персонализация оказалась выдумкой → это не ЧП, а норма генерации: правило «каждый факт в письме — из резюме кандидата», выборочная сверка — всегда (для правок — атом core `02-iterate.md`: конкретно, по 1–3 за раз); отказ на полстраницы с извинениями → отказ хороший, когда короткий, честный и тёплый: 4–6 предложений; ученик хочет «отправь письма» → стоп, из курса ничего никуда не отправляется — артефакт это файлы, отправка из его рабочей почты руками.
- Назови типичное заблуждение вслух: «сгенерированное письмо = обман кандидата» — нет, если факты честные и тон твой. Обман — это «Уважаемый кандидат!» всем под копирку. Шаблон писал ты, факты — из резюме, агент только собрал одно с другим.
- В конце — вызови проверку и, если passed, похвали конкретно: у каждого кандидата из таблицы — личное письмо, включая отказы, которые обычно висят неделями. Отметь пойманную выдумку, если была: «ты уже ловишь галлюцинации фактчеком — это навык, который дороже самой генерации». Открой следующую миссию.

## Ученику (живой сценарий)

«Представь: шортлист из прошлой миссии согласован. Менеджер выбрал троих на интервью. У тебя в почте — остальные, и каждому надо ответить. Знаешь, сколько в среднем висят отказы? У большинства — "потом". А кандидаты тем временем пишут отзывы про "динамично развивающуюся компанию, которая даже не ответила". Сегодня закроем всех — и не под копирку.» (~30–45 минут)

Что делаем руками:

1. Попроси агента сделать заготовки шаблонов `sandbox/hr/letters/templates/invite.md` и `decline.md` с плейсхолдерами. Перепиши их своим тоном — если есть письмо, которым ты доволен, дай его агенту как образец.
2. Попроси сгенерировать по `report.md` письмо каждому кандидату в `sandbox/hr/letters/out/`: шортлисту — приглашение, остальным — отказ, каждому — с конкретикой из ЕГО резюме, без выдумок.
3. Проверь два письма против резюме: все факты на месте? Нашёл выдумку — скажи агенту, что именно, и попроси перегенерировать строго по резюме.
4. Прочитай один отказ вслух. Канцелярит или обидно — правь конкретными замечаниями, пока не зазвучит по-человечески.

К концу у тебя есть письма всем кандидатам из таблицы — в твоём тоне, с честными фактами — и привычка сверять сгенерированное с источником.

## Артефакт

`sandbox/hr/letters/templates/` с `invite.md` и `decline.md` (шаблоны с плейсхолдерами, в тоне ученика) и `sandbox/hr/letters/out/` — по письму на каждого кандидата из report.md, с персонализацией из его резюме.
