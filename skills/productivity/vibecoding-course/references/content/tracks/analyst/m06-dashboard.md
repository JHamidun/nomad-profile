# Миссия 6 — Дашборд вместо скриншота

ROLE: analyst
GOAL: Ученик умеет собирать из своих данных самодостаточный HTML-дашборд: 2–3 графика, каждый отвечает на конкретный вопрос, файл открывается у любого человека без установки программ и без интернета.
WHY: Скриншот таблицы в презентации умирает в день отправки. Файл `dashboard.html`, который директор открывает двойным кликом — в самолёте, без VPN, без «у меня не установлен ваш Power BI», — живёт и работает. Для большинства регулярных вопросов бизнеса такого файла достаточно.

## Наставнику (как вести — читает Claude Code)

- НЕ лекция. Начни с `answers.md` из прошлой миссии: спроси, какие 2–3 вопроса из тех (или новых) руководство задаёт регулярно — из них и собирается дашборд. Проговори принцип: дашборд — это ответы на вопросы, а не «все данные сразу».
- Скажи оценку времени: 45–60 минут.
- Дай сделать РУКАМИ, по одному микро-шагу:
  1. Бриф — навык из миссии 1, теперь на боевой задаче. Пусть заполнит короткий бриф (можно прямо в чате или файлом): цель, для кого, какие 2–3 графика, критерии готовности. Один критерий продиктуй жёстко: «открывается при выключенном интернете» — значит, данные зашиты внутрь файла и никаких внешних ссылок на библиотеки.
  2. Сборка. Пусть попросит агента собрать `sandbox/datalab/dashboard.html` по брифу из `clean.csv` (или `data.db`). Отдельно скажи ученику проговорить агенту: заголовок каждого графика — вывод («Выручка растёт третий месяц подряд»), а не «График 1».
  3. Честная проверка. Выключить Wi-Fi — открыть файл. Работает? Теперь сверить числа на графиках с `answers.md`: расхождение на дашборде, который уйдёт наверх, стоит дороже часа работы.
  4. Итерации. Что-то не читается, лишнее, мелкое — конкретные правки по одной-две, как учились: не «сделай красивее», а «подписи месяцев по оси X, третий график убери».
  5. Коммит в git.
- Точки помощи: агент подключил библиотеку графиков по внешней ссылке (CDN) → пусть ученик попросит «зашей всё в сам файл, без внешних ссылок» — и перепроверит без интернета; графики красивые, но ни о чём → верни к вопросам: один график — один вопрос — один вывод в заголовке; число на графике не совпало с answers.md → стоп, разбираемся до отправки, а не после (обычно график считает по сырым данным или с другим фильтром); дашборд распух на шесть графиков → ужать до трёх: внимание смотрящего — тоже ресурс.
- Назови типичное заблуждение вслух: «дашборд — это BI-система, долго и дорого». Для регулярных вопросов уровня отдела хватает одного HTML-файла, собранного за вечер. BI понадобится позже — когда вопросов станет сорок, а смотрящих — сто.
- В конце — вызови проверку и, если passed, похвали конкретно: вместо скриншота, который устареет завтра, у него файл, который можно отправить кому угодно — и тот откроется. Скажи, что осталась финальная миссия — собрать всё в конвейер.

## Ученику (живой сценарий)

«Представь: твои три ответа руководителю понравились. Настолько, что теперь он хочет "такое же, но каждую неделю и красиво". Посылать каждый понедельник скриншоты из Excel — путь в никуда. Соберём дашборд — один файл, который открывается у всех.» (~45–60 минут)

Что делаем руками:

1. Выбери 2–3 вопроса, на которые дашборд должен отвечать. Не «показать данные», а вопросы: что с выручкой по месяцам? кто тянет продажи? где просадка?
2. Напиши бриф: цель, для кого, какие графики, критерии готовности. Один критерий обязателен: файл открывается при выключенном интернете — все данные и код графиков внутри, никаких внешних ссылок.
3. Попроси агента собрать `sandbox/datalab/dashboard.html` по брифу. Отдельно скажи: заголовок каждого графика — готовый вывод, а не «График 1».
4. Проверь честно: выключи Wi-Fi и открой файл. Потом сверь каждое число на графиках с `answers.md` — расхождения чинить до отправки.
5. Правь конкретными замечаниями, по одному-два за раз. Готово — закоммить в git.

К концу у тебя есть файл, который не стыдно отправить руководителю прямо сейчас.

## Артефакт

`sandbox/datalab/dashboard.html` — самодостаточный дашборд: 2–3 графика с заголовками-выводами, данные зашиты в файл, открывается локально без интернета.
