# Миссия 0 — Первый запуск: осмотрись

ROLE: CORE
GOAL: Ученик понимает, что перед ним агент с руками (файлы, команды), и умеет получить от него первое реальное изменение — созданный файл.
WHY: В любой роли первый барьер один и тот же: непонятно, что это за окно и чем оно отличается от привычного чата. Пока страх первого запуска не снят, ни лендинг для кампании, ни прототип фичи, ни калькулятор КП не начнутся.

## Наставнику (как вести — читает Claude Code)

- НЕ лекция. Сначала спроси: запускал ли Claude Code (или Codex) раньше, и какие задачи у него в работе сейчас — это пригодится для «Хочу собрать».
- Скажи оценку времени: 15–20 минут.
- Дай сделать РУКАМИ, по одному микро-шагу:
  1. Начни с себя, не с вопроса ученику: коротко покажи, что ты УЖЕ прочитал эту папку — назови, что здесь курс на столько-то миссий и есть его трек. Проговори вслух: обычный чат так не умеет, у меня есть доступ к твоим файлам. Это и есть разница, которую сегодня ловим.
  2. Мгновенный видимый результат: скажи «назови своё имя — и я прямо сейчас создам файл, ты увидишь, как он появляется». Создай `sandbox/about-me.md` с полем Имя и попроси открыть его в редакторе или проводнике. Первое «вау»: сказал словами — на диске появилась вещь.
  3. Теперь дозаполни этот же файл: пусть попросит добавить два поля — Роль и «Хочу собрать» (реальную вещь из его работы — пригодится в миссии 2). Формулировку просьбы не диктуй дословно — подскажи только состав.
  4. Пусть откроет файл и проверит: то ли записано. Не то — пусть попросит поправить (первая итерация, не называя её умным словом).
- Точки помощи: если пугается терминала → напомни: пишем обычным русским языком, никаких команд учить не надо; если файла не видно → пусть спросит агента «покажи, что лежит в sandbox/»; если начал диктовать агенту технические шаги → останови: на этом курсе ученик формулирует задачу, агент решает как.
- Назови типичное заблуждение вслух: «это просто чат с ИИ» — нет: агент читает и меняет файлы, запускает команды, проверяет свою работу.
- В конце — вызови проверку (скилл course-check) и, если passed, похвали конкретно (первое изменение реального файла сделано словами, без единой строчки кода) и открой следующую миссию.

## Ученику (живой сценарий)

«Представь: тебе прилетело от руководителя — "говорят, эти ИИ-агенты умеют собирать рабочие инструменты; разберись, что это, к пятнице расскажешь". Ты открыл эту папку в Claude Code и видишь строку ввода. С этого места начинаем.» (~15–20 минут)

Что делаем руками:

1. Агент сам покажет, что уже прочитал папку, — это его отличие от чата: у него есть доступ к твоим файлам.
2. Назови агенту своё имя и попроси создать файл — посмотри, как `sandbox/about-me.md` появляется на диске. Сказал словами — вещь появилась.
3. Дозаполни этот же файл: попроси добавить твою Роль и что ты хочешь собрать на курсе (реальную вещь из работы — пригодится в миссии 2).
4. Открой файл и проверь. Записано не то — попроси агента поправить.

К концу у тебя есть первый файл, созданный по твоей просьбе, — и понимание, с кем ты разговариваешь.

## Артефакт

Файл `sandbox/about-me.md` с заполненными полями: Имя, Роль, Хочу собрать.
