# Миссия 4 — Ассеты без стоков

ROLE: designer
GOAL: Ученик умеет ставить агенту арт-дирекшн через стиль-спеку и получать консистентный набор графики — SVG-иконки, логотип-заглушку, фавиконку — в едином стиле и в цветах своих токенов.
WHY: Знакомая история: к странице нужны десять иконок, на стоках всё вразнобой — тут линия 1.5px, там 2.5px, углы разные, приходится перерисовывать каждую. Дизайнер, который умеет продиктовать агенту стиль-спеку («сетка 24, штрих 2px, скругления 2px»), получает набор в одном стиле за один заход — и это тот же навык арт-дирекшна, которым он руководит иллюстратором, только исполнитель отвечает за минуты.

## Наставнику (как вести — читает Claude Code)

- НЕ лекция. Сначала спроси: какие иконки реально нужны его прототипу из миссии 3 (навигация, действия, статусы — пусть назовёт 6–8 конкретных). Работаем на его проект, не «набор иконок вообще».
- Скажи оценку времени: 30–45 минут.
- Дай сделать РУКАМИ, по одному микро-шагу:
  1. Стиль-спека. Пусть создаст `sandbox/design/assets/STYLE.md` — правила, по которым будет рисоваться вся графика: сетка (например, 24×24), толщина штриха (stroke, например 2px), скругления углов, залитые или контурные, цвета — по именам токенов (`--color-fg`, `--color-primary`), чего в стиле НЕТ (теней, градиентов, 3D). Это и есть арт-дирекшн, записанный текстом: чем точнее спека, тем консистентнее набор.
  2. Иконки. Пусть попросит агента сгенерировать 6–8 SVG-иконок по списку — строго по STYLE.md, каждая отдельным файлом в `sandbox/design/assets/icons/`. SVG — это код, агент пишет его сам, интернет не нужен.
  3. Витрина. Пусть попросит собрать `sandbox/design/assets/index.html` — страницу-витрину, где все иконки стоят рядом сеткой, на токенах проекта. Витрина — главный инструмент контроля: разнобой виден мгновенно, только когда всё рядом.
  4. Контроль и правки. Пусть посмотрит на витрину взглядом арт-директора: какая иконка выбивается? Правка — через спеку: не «перерисуй колокольчик», а «у колокольчика штрих тоньше остальных — приведи к 2px из STYLE.md».
  5. Логотип и фавиконка. Пусть попросит агента сделать `logo.svg` (простая графическая заглушка: знак + название проекта в стиле спеки) и `favicon.svg`, и подключить фавиконку к прототипу из миссии 3.
- Точки помощи: иконки получились разностильными → спека недоопределена: добавь в STYLE.md недостающее правило (штрих? углы? оптический размер?) и попроси перегенерировать по обновлённой спеке; иконка непонятна без подписи → это нормальный повод упростить метафору, пусть скажет агенту, что должен считываться за секунду; хочется фотореализма или сложной иллюстрации → SVG для этого не лучший путь, скажи честно: если у ученика есть доступ к генератору картинок — можно добавить растровую обложку отдельно, но проверка миссии этого не требует и без интернета это не сделать; цвета в иконках захардкожены → пусть попросит агента использовать currentColor или значения токенов, чтобы иконки перекрашивались вместе с темой.
- Назови типичное заблуждение вслух: «сгенерированное = неконсистентное» — разнобой даёт не генерация, а отсутствие спеки; у иллюстратора без брифа вышло бы так же.
- В конце — вызови проверку и, если passed, похвали конкретно: набор графики в одном стиле, собранный по его собственной стиль-спеке, — и витрина, которой это можно доказать. Открой финальный проект.

## Ученику (живой сценарий)

«Представь: прототип собран, завтра демо, и тут ты замечаешь — иконки-то временные, надёрганные откуда попало. Одна жирная, другая тощая, третья с тенью. Стоки дадут такой же винегрет. Полдня перерисовывать нет. Есть агент и твой навык арт-дирекшна.» (~30–45 минут)

Что делаем руками:

1. Напиши стиль-спеку `assets/STYLE.md`: сетка, толщина штриха (stroke), скругления, цвета по именам токенов, и отдельно — чего в стиле нет. Представь, что отдаёшь бриф иллюстратору, который сделает буквально по написанному.
2. Составь список из 6–8 иконок, которые реально нужны твоему прототипу, и попроси агента сгенерировать их SVG строго по спеке — каждую отдельным файлом.
3. Попроси собрать витрину `assets/index.html` — все иконки рядом, сеткой. Посмотри взглядом арт-директора: что выбивается?
4. Правь через спеку: «штрих у этой тоньше остальных — приведи к спеке». Спека — закон, правки — ссылками на неё.
5. Добавь `logo.svg` и `favicon.svg` в том же стиле, фавиконку подключи к прототипу.

К концу у тебя графика в одном стиле — и опыт арт-дирекшна, где исполнитель отвечает за минуты.

## Артефакт

Папка `sandbox/design/assets/` с: `STYLE.md` (стиль-спека графики), `icons/` (6+ SVG-иконок по спеке), `logo.svg`, `favicon.svg` и `index.html` — витрина, где весь набор виден рядом.
