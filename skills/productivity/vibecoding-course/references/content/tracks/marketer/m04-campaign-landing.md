# Миссия 4 — Лендинг кампании за вечер

ROLE: marketer
GOAL: Ученик формулирует оффер и собирает с агентом посадочную страницу кампании: один главный CTA, первый экран, отвечающий на «что это / почему мне / почему сейчас», форма, которая запоминает UTM-метки.
WHY: Знакомая ситуация: запуск в понедельник — вебинар, лид-магнит, промо, — а страницы нет: подрядчик занят, на конструкторе тариф кончился, дизайнер в отпуске. Раньше это означало перенос запуска. Теперь посадочная под кампанию собирается за вечер с агентом — если маркетолог умеет внятно сформулировать оффер. Оффер и есть главная работа этой миссии; вёрстка — работа агента.

## Наставнику (как вести — читает Claude Code)

- НЕ лекция. Сначала спроси: что ученик реально запускает в ближайший месяц (вебинар, лид-магнит, набор на курс, акция)? Если ничего — пусть возьмёт прошлую или вымышленную кампанию, но с конкретикой: продукт, аудитория, дата.
- Скажи оценку времени: 60–90 минут.
- Дай сделать РУКАМИ, по одному микро-шагу:
  1. Оффер до вёрстки. Пусть заполнит `sandbox/marketing/campaign/offer.md`: для кого (сегмент, не «все»), обещание (результат клиента, не процесс: «команда начнёт применять ИИ в задачах», а не «мы проведём обучение»), почему сейчас (дата, дедлайн, ограничение), соцпруф (цифры, имена, кейсы — только реальные), CTA (текст кнопки — ценность, не действие: «Занять место», а не «Отправить»).
  2. Бриф лендинга с критериями готовности. Обязательный критерий: первый экран отвечает на три вопроса — что это, почему мне, почему сейчас — за 5 секунд (атом `marketer/01-landing-answers.md`, перескажи коротко). Один главный CTA, форма из 2–3 полей.
  3. Пусть попросит агента собрать `sandbox/marketing/campaign/landing/index.html` по offer.md и брифу. Дальше 1–2 круга правок конкретными замечаниями («заголовок — из обещания, не из названия продукта», «убери второй CTA»), не «сделай получше» (атом `02-iterate.md`).
  4. Связка с миссией 3: пусть попросит агента сделать так, чтобы форма запоминала utm-метки из адреса страницы (скрытые поля) — тогда с каждой заявкой приедет её источник. Проверка: открыть лендинг по ссылке из своего генератора (с `?utm_source=...`) и убедиться, что страница открылась, а заявка «знает» источник (агент подскажет, как посмотреть).
- Точки помощи: оффер про «мы» и процесс → переверни в результат клиента; на первом экране три кнопки → оставить одну главную, остальное вниз или в текст; страница-простыня → первый экран = заголовок, подзаголовок, кнопка, соцпруф, остальное ниже; форма из 8 полей → 2–3 поля, каждое лишнее поле режет конверсию; соцпруф выдуман агентом → правило: цифры и имена только из offer.md, нет — блок убираем.
- Назови типичное заблуждение вслух: «главное, чтобы было красиво» — нет: сначала ясность за 5 секунд, потом красота; красивая страница с мутным оффером не конвертит.
- В конце — вызови проверку и, если passed, похвали конкретно: назови самую сильную строку его оффера и покажи, как она стала заголовком. Открой следующую миссию.

## Ученику (живой сценарий)

«Представь: в понедельник запуск, а посадочной страницы нет и не предвидится — все, кто "умеет в лендинги", заняты. Отменять запуск из-за страницы — обидно. Собираем её сами: ты отвечаешь за оффер, агент — за вёрстку.» (~60–90 минут)

Что делаем руками:

1. Заполни `sandbox/marketing/campaign/offer.md`: для кого, обещание (результат, не процесс), почему сейчас, соцпруф (только реальный), текст кнопки. Это самая важная часть миссии — не торопись.
2. Составь бриф лендинга с критериями готовности. Главный критерий: незнакомый человек за 5 секунд понимает, что это, зачем ему и почему сейчас.
3. Попроси агента собрать `sandbox/marketing/campaign/landing/index.html` по офферу и брифу. Открой, пройдись по критериям, дай 1–2 конкретные правки.
4. Попроси агента научить форму запоминать utm-метки из адреса. Открой лендинг по ссылке из твоего генератора из прошлой миссии — и проверь, что метки доехали.

К концу у тебя есть посадочная страница твоей кампании, которая знает, откуда пришёл каждый, кто оставил заявку.

## Артефакт

`sandbox/marketing/campaign/offer.md` (для кого, обещание, почему сейчас, соцпруф, CTA) и `sandbox/marketing/campaign/landing/index.html` — лендинг с одним главным CTA, формой из 2–3 полей и скрытыми utm-полями.
