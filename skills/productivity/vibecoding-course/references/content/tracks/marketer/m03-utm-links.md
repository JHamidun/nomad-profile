# Миссия 3 — Кампания без слепых зон (UTM)

ROLE: marketer
GOAL: Ученик размечает ссылки кампании по единому словарю UTM и собирает себе генератор ссылок, которым пользуется вместо онлайн-сервисов и разнобоя в блокноте.
WHY: Классика жанра: кампания идёт в трёх каналах, через неделю руководитель спрашивает «откуда лиды?» — а в Метрике каша, потому что один пост размечен `telegram`, другой `Telegram_post`, третий вообще без меток. Дальше все решения о бюджете принимаются вслепую. Словарь меток + свой генератор закрывают эту дыру за один вечер.

## Наставнику (как вести — читает Claude Code)

- НЕ лекция. Сначала спроси: какие каналы у ученика в работе прямо сейчас (Telegram-канал, посевы, VK Ads, Директ, email-рассылка, блогеры) и была ли уже ситуация «не поймёшь, откуда пришли». Его каналы — материал этой миссии.
- Скажи оценку времени: 30–45 минут.
- Дай сделать РУКАМИ, по одному микро-шагу:
  1. Словарь. Пусть попросит агента создать `sandbox/marketing/utm/utm-rules.md` с тремя разделами, озаглавленными именами параметров — `utm_source` (откуда конкретно: `telegram`, `vk`, `yandex-direct`, `email`…), `utm_medium` (тип трафика: `cpc`, `social`, `email`, `qr`…), `utm_campaign` (шаблон названия, например `<продукт>-<месяц>`, латиницей) — плюс три правила написания: латиница, нижний регистр, дефисы вместо пробелов. Заголовки разделов — именно полными именами параметров (по ним пройдёт проверка), значения — из ЕГО реальных каналов, не абстрактные.
  2. Бриф генератора — это повторение навыка миссии 1: цель, что внутри, критерии готовности. Внутри: поле для URL, выпадающие списки source/medium из словаря, поле campaign, собранная ссылка, кнопка «скопировать».
  3. Пусть попросит агента собрать `sandbox/marketing/utm/index.html` строго по брифу — и чтобы значения списков агент взял из utm-rules.md, а не придумал.
  4. Проверка боем: ученик собирает 2–3 ссылки для своей реальной кампании и открывает одну в браузере — метки должны быть видны в адресной строке.
- Точки помощи: в метках кириллица или пробелы → верни к правилам из словаря (ломают сравнение источников и иногда сами ссылки); путает source и medium → source = «откуда конкретно» (vk), medium = «какого типа трафик» (cpc или social); генератор выдаёт значения не из словаря → пусть скажет агенту: «списки бери из utm-rules.md»; «зачем свой, есть онлайн-генераторы» → онлайн-генератор не знает твой словарь, а каша начинается именно с разнобоя значений.
- Назови типичное заблуждение вслух: «аналитика сама поймёт, откуда переход» — нет: переходы из мессенджеров, приложений и QR-кодов без меток падают в «неизвестный источник» (атом `marketer/00-utm-discipline.md`, перескажи в двух предложениях).
- В конце — вызови проверку и, если passed, похвали конкретно: теперь у каждого перехода его кампании есть имя и фамилия, и это его собственный инструмент, а не закладка на чужой сервис. Открой следующую миссию.

## Ученику (живой сценарий)

«Представь: ты запускаешь кампанию в трёх каналах — пост в Telegram, таргет в VK, письмо по базе. Через неделю планёрка, вопрос один: "какой канал привёл заявки?" Если ссылки не размечены — ответа не будет, будет "ну, наверное, телеграм". Сегодня делаем так, чтобы этот вопрос больше никогда не был страшным.» (~30–45 минут)

Что делаем руками:

1. Заведи с агентом словарь меток `sandbox/marketing/utm/utm-rules.md`: твои источники (source), типы трафика (medium), шаблон названия кампании (campaign) и правила написания — латиница, нижний регистр, дефисы. Пиши про свои каналы, не учебные.
2. Составь короткий бриф генератора ссылок: что на странице, откуда значения, критерии готовности.
3. Попроси агента собрать `sandbox/marketing/utm/index.html` по брифу — со списками из твоего словаря и кнопкой «скопировать».
4. Собери 2–3 ссылки для своей ближайшей кампании. Открой одну в браузере и посмотри на адресную строку: вот твои метки.

К концу у тебя есть словарь, генератор и размеченные ссылки — слепых зон в кампании стало меньше.

## Артефакт

`sandbox/marketing/utm/utm-rules.md` (словарь: source, medium, шаблон campaign, правила написания) и `sandbox/marketing/utm/index.html` — работающий генератор UTM-ссылок со значениями из словаря.
