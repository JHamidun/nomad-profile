# Course Role — выбор и смена роли

Процедура выбора/смены роли ученика. Вызывается из driver'а (SKILL.md, шаг 2), когда `role` пустая, или ученик говорит «сменить роль», «я маркетолог», «выбрать роль».

Пути как в SKILL.md: **CONTENT** = `${HERMES_SKILL_DIR}/references/content` (read-only), **HOME** = вывод `python ${HERMES_SKILL_DIR}/scripts/_course_home.py` (writable).

Роль определяет, на язык чьей работы наставник переводит миссии: примеры, сценарии «Ученику», WHY. Механика миссий одна для всех — меняется мясо примеров.

## Выбор роли (роль пустая)

1. Прочитай список ролей из `<CONTENT>/config.yaml` → `roles` (key, title, example).
2. Покажи ученику нумерованный список: название роли + пример того, что человек этой роли собирает на курсе (поле `example`).
3. Спроси, что ближе к его работе. Если ученик описывает себя словами («я запускаю рекламу», «я нанимаю людей») — предложи подходящую роль сам и уточни, попал ли.
4. Ничего не подходит — предложи ближайшую по духу и скажи честно, что примеры будут «по мотивам»; курс от этого не ломается.

## Запись в состояние

В `<HOME>/state.json` запиши:

```json
"role": "<key из config.yaml>",
"role_title": "<title из config.yaml>"
```

и обнови `updated_at`. При ПЕРВОМ выборе роли больше ничего не трогай: порядок треков задан в `config.yaml` (`order`: сначала `_core`, потом трек роли), текущую миссию двигает driver. (Смена роли посреди трека роли — исключение, см. ниже.)

## Смена роли на ходу

Ученик может сменить роль в любой момент — это безопасно:

1. Спроси, точно ли меняем (одним вопросом, без драмы).
2. Перепиши `role` / `role_title`, обнови `updated_at`.
3. Пройденные миссии и баллы НЕ сбрасывай — фундамент общий для всех ролей.
4. Если ученик уже в треке роли (`track` не `_core` и не совпадает с новой ролью) — переключи state сам, иначе driver продолжит вести его по СТАРОМУ треку до конца: `track` = key новой роли, `current_mission` = первая миссия её трека (первый файл `m*` по сортировке имён в `<CONTENT>/tracks/<новая роль>/`). Пройденные миссии и баллы старого трека оставь в `completed`/`scores` как есть. Скажи честно: трек новой роли начнётся с его первой миссии.

## После выбора

Одной фразой свяжи роль с курсом («значит, примеры будут про <example>») и передай руль обратно driver'у — вести текущую миссию.
